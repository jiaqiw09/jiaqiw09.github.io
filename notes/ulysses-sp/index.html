ULySSes Sequence Parallelism (SP) 流程图

1. 核心原理

▤

非 Attention 层：

Embedding / LayerNorm / MLP
按序列切分仍然正确
（per-token 独立）

⟐

Attention 层：

需要完整序列
直接按序列切分会导致错误
因为 QK^T 需要每个 query
看见所有 key

◫

关键性质：

不同 attention head
彼此独立
因此可以按 head
分工计算

⇄

解决思路：

通过两次 All-to-All 在
「部分序列 + 全部头」↔
「完整序列 + 部分头」之间切换

💡 核心思想：牺牲部分头，换取完整序列，从而保证 Attention 计算正确。

例：seq 被 2 卡切成前半 / 后半；进入 Attention 前，每卡换到完整 seq，但只保留一半 heads。

4. 为什么通常要用 Flash Attention?

(1) UlySSes 改变的是分布式布局

第一次 All-to-All 之后，
每张卡拿到的是
「完整 seq + 部分 heads」，
不是「短 seq + 全部 heads」。

(2) 普通 attention 的问题

若直接构造 attention scores，
shape 是 [B, H, S, S]。
当 seq_len 很长时，
S × S 显存会爆炸。

例：S = 128K, heads_per_rank = 8，
bf16 时，仅 scores 就约 274 GB。

(3) Flash Attention 的作用

FA 按 block 分块计算，
在线 softmax，
不显式保存完整 S × S
attention matrix，
显存从接近 O(S²)
降到更接近 O(S)。

(4) 结论

UlySSes 负责跨卡布局切换；
Flash Attention 负责让每张卡上的
full-seq attention 算得动。
所以工程上二者几乎绑定使用。

💡 补充：理论上也可换成 SDPA / NPU fused attention 等高效 kernel，但前提仍然是它必须支持 full-seq + local-head 的高效计算。

5. SP 下的关键特殊点（举例说明）

(1) Loss 的标签对齐不能本地做

GPU0
labels = [A, B, C]
GPU1
labels = [D, E, F]

GPU0 最后一个 logits 应预测 D，但 D 在 GPU1 上，直接本地 shift 会错。

  1. ❶ All-gather labels / loss_weights
  2. ❷ 全局 shift labels [..., 1:]
  3. ❸ 末尾补 −100
  4. ❹ 再按序列维切分

GPU0　shift_labels = [B, C, D]

GPU1　shift_labels = [E, F, -100]

最后用对齐后的 shift_labels 与 logits
计算加权交叉熵。

(2) attention_mask 也必须补齐为全局序列

本地 rank 只有半段序列的 mask，
进入 attention 前需要
All-gather 成 global_mask。
否则 causal / padding
语义都不完整。

例：本地 mask = (2, 4)，
拼成 global_mask = (2, 8)。

□ 1: 有效　 ▧ 0: padding / 不可见

(3) Backward 的通信方向会自动反转

前向第一次 All-to-All 是
scatter 头 / gather 序列；
反向时对应变成
scatter 序列 / gather 头。
也就是通信的转置，
梯度沿相反路径流回。

Forward: (2,4,16,64)→(2,8,8,64)
Backward: grad 反向换回

前向：头 → 序列 →

← 反向：序列 → 头

(4) 梯度范数 / 标量统计要做组内汇总

每个 CP rank 只看到局部序列，
局部 grad_norm 不能直接当全局值。
要在 CP 组内对 grad_norm² 做
All-Reduce(SUM)，再开方。

例：GPU0 = 3.2，GPU1 = 2.8
→ 全局 = √(3.2² + 2.8²) ≈ 4.25

GPU0
grad_norm² = 10.24
GPU1
grad_norm² = 7.84

↓ All-Reduce(SUM)

全局 grad_norm = 4.25

6. 一句话总结

★

SP 的本质是：非 Attention 层保持序列切分；进入 Attention 前通过 All-to-All 把布局切换成
「完整序列 + 部分头」；在本地完成 full-seq attention 后再切回「部分序列 + 全部头」；
而 loss、mask、梯度统计等特殊环节需要额外做跨 rank 对齐与汇总。
