核心原理

序列切分适合逐 token 的操作，注意力却依赖完整上下文。Ulysses 在注意力前后交换序列和头维，让每张卡只负责部分头，同时读到每个头的完整序列。

01

非 Attention 层：

Embedding / RMSNorm / MLP 按序列切分仍然正确 （per-token 独立）

02

Attention 层：

需要完整序列 直接按序列切分会导致错误 因为 QK^T 需要每个 query 看见所有 key

03

关键性质：

不同 attention head 彼此独立 因此可以按 head 分工计算

04

解决思路：

通过两次 All-to-All 在 「部分序列 + 全部头」↔ 「完整序列 + 部分头」之间切换

核心思想：牺牲部分头，换取完整序列，从而保证 Attention 计算正确。

例：seq 被 2 卡切成前半 / 后半；进入 Attention 前，每卡换到完整 seq，但只保留一半 heads。

为什么通常要用 Flash Attention?

序列布局的变化使本地注意力看到完整序列，长序列仍会带来很大的打分矩阵。Flash Attention 用块内计算和在线归一化控制这部分存储。

(1) UlySSes 改变的是分布式布局

第一次 All-to-All 之后， 每张卡拿到的是 「完整 seq + 部分 heads」， 不是「短 seq + 全部 heads」。

(2) 普通 attention 的问题

若直接构造 attention scores， shape 是 [B, H, S, S]。 当 seq_len 很长时， S × S 显存会爆炸。

例：B = 1, S = 128K, heads_per_rank = 8， bf16 时，仅 scores 就约 274 GB。

(3) Flash Attention 的作用

FA 按 block 分块计算， 在线 softmax， 不显式保存完整 S × S attention matrix， 显存从接近 O(S²) 降到更接近 O(S)。

(4) 结论

UlySSes 负责跨卡布局切换； Flash Attention 负责让每张卡上的 full-seq attention 算得动。 所以工程上二者几乎绑定使用。

补充：理论上也可换成 SDPA / NPU fused attention 等高效 kernel，但前提仍然是它必须支持 full-seq + local-head 的高效计算。

SP 下的关键特殊点（举例说明）

主流程之外，标签、掩码和梯度都需要检查各自的归属。依次核对跨片 Shift、全局 mask、反向通信的轴和梯度归约范围。

(1) 跨分片的 Loss 标签对齐

GPU0 labels = [A, B, C]
GPU1 labels = [D, E, F]

GPU0 最后一个 logits 应预测 D，但 D 在 GPU1 上，直接本地 shift 会错。

  1. ❶ 取得完整 labels 与对应 loss_weights
  2. ❷ 全局 shift labels [..., 1:]
  3. ❸ 末尾补 −100
  4. ❹ 将对齐后的标签和权重按序列切分

GPU0　shift_labels = [B, C, D]

GPU1　shift_labels = [E, F, -100]

切分前即可完成全局 shift。若已经切分，只需补齐跨片边界的目标；最后用对齐的标签、权重与 logits 计算损失。

(2) 使用全局序列对应的 mask

如果 padding mask 随序列切分，可在进入 attention 前通过 All-gather 拼回完整 mask；若已保留完整 mask，可以直接复用。因果约束另外由位置或 kernel 的 causal 模式处理。

例：本地 mask = (2, 4)， 拼成 global_mask = (2, 8)。

□ 1: 有效　 ▧ 0: padding / 不可见

(3) Backward 的通信方向会自动反转

前向第一次 All-to-All 是 scatter 头 / gather 序列； 反向时对应变成 scatter 序列 / gather 头。 也就是通信的转置， 梯度沿相反路径流回。

Forward: (2,4,16,128)→(2,8,8,128) Backward: grad 反向换回

前向：头 → 序列 →

← 反向：序列 → 头

(4) 按参数分片汇总梯度范数

完成梯度同步后，对互不重叠的参数梯度分片计算平方和，再跨持有这些分片的 rank 求和并开方。仅按序列切分，不能推出参数梯度也互不重叠。

例：两个不重叠分片的范数为 3.2 和 2.8 → 全局 = √(3.2² + 2.8²) ≈ 4.25

参数分片 0 grad_norm² = 10.24
参数分片 1 grad_norm² = 7.84

↓ All-Reduce(SUM)

TAKEAWAY

一句话总结

SP 的本质是：非 Attention 层保持序列切分；进入 Attention 前通过 All-to-All 把布局切换成 「完整序列 + 部分头」；在本地完成 full-seq attention 后再切回「部分序列 + 全部头」； loss 和 mask 需要与全局序列对齐；梯度范数的汇总范围由参数梯度分片方式决定。
