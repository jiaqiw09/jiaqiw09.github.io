01

核心原理

序列切分天然适合逐位置操作。Ulysses 把注意力前后的跨卡交换做成一对互逆的维度重排。

01 起点

逐位置层独立

Embedding / RMSNorm / MLP

每个 token 只读自己的 hidden state，因此序列切开仍然可以计算。

02 矛盾

Attention 需要完整序列

QKᵀ → softmax → V

每个 Query 需要同一注意力头覆盖的 Key 和 Value，直接按本地序列计算会漏读历史。

03 性质

多头可独立计算

单个注意力头的分数和输出按头独立。GQA 的同组 Query 头仍共享对应的 KV 头。

04 优化

两次换轴保存数学结果

进入注意力前换到完整序列和部分头，返回后恢复部分序列和全部头。

数学本质 ·牺牲部分本地 heads，换回这些 heads 的完整序列。以两卡为例，进入注意力前每张卡从前半或后半序列换成全序列、半数 heads。

04

为什么通常要搭配 FlashAttention

换轴解决注意力访问完整序列的问题，单头打分依然随长度呈平方增长。FlashAttention 通过分块和在线归一化降低中间显存。

01 布局

Ulysses 管布局

第一次交换后，每卡持有完整序列及分配到的注意力头。

02 显存瓶颈

显式分数矩阵代价

[B,H,S,S] · bf16

B=1、每卡 H=8、S=128K 时，仅分数约 274.88 GB（256 GiB）。

03 破局

在线分块

按块计算分数。在线维护 softmax 统计量，避免显式保存完整 S×S 矩阵。

04 组合

组合效果

Ulysses 负责跨卡切换布局，FlashAttention 负责单卡高效执行满序列的本地头计算。

工程边界 ·SDPA 或 NPU fused attention 也可承载这一路径，条件是内核支持 full-seq + local-head 的输入布局。

05

训练期的四个关键工程边界

训练期还要核对监督信号、掩码和梯度的归属。下面分别追踪四处最容易发生分片错位的边界。

对不重叠的参数梯度分片做局部平方和，再在对应参数分片组求和。仅序列被切分不代表参数梯度不重叠。

06

方案与通信显存账本

用同一组工程规模比较单层稳态前向。通信按每 Rank 发出的逻辑 payload 计数，显存列只比较分数矩阵口径。

方案单卡激活形状（B,S,H,D）分数矩阵峰值（仅分数缓冲）单层跨卡逻辑发送 / Rank
单卡满序列 MHAQ/K/V: (1,131072,32,128)B·H·S²·2 = 1,099,511.63 MB（1,024 GiB）0 MB
Ring AttentionQ/K/V: (1,32768,32,128)；逐轮接入远端 KV 块每轮显式物化上界 B·H·(S/P)²·2 = 68,719.48 MB；在线分块不分配整块(P−1)·2·B·(S/P)·H·D·2 = 1,610.61 MB（1,536 MiB）
Ulysses SP + FlashAttention切分态 (1,32768,32,128) → 计算态 (1,131072,8,128)在线分块，无完整 BH/P×S×S 分数张量。若显式存全分数则 274,877.91 MB（256 GiB）(1−1/P)·(3+1)·B·(S/P)·H·D·2 = 805.31 MB（768 MiB）

计量口径 ·MB 按 10⁶ B，MiB 按 2²⁰ B。Ring 按每卡转发 P−1 轮本地 KV 分片估算，Ulysses 按两次均匀 All-to-All 只计对端份额。接收量、协议字节、工作区和反向均未折入。

TAKEAWAY

SP 让逐位置层保留序列切分，在注意力前把局部序列换成完整序列和部分头，再换回原布局。Loss 和 mask 按全局序列对齐，梯度跨哪些 Rank 归约由参数分片归属决定。
