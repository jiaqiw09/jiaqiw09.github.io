1. Attention 在模型中的作用

输入文字会被切成 token，然后变成数字向量。经过若干层处理后，每个位置都有一个向量，例如：

xt=[0.2,−0.7,1.3,…]
  • t：第几个位置。
  • xt：这个位置当前的表示。
  • 向量中有 d 个数字，就叫 d 维向量。

可以把向量理解成“模型对这个位置的数字化描述”。这些维度由训练共同形成，通常不能逐个命名为“人物”“地点”等人类概念。

Attention 的任务是：根据当前位置需要什么，从其他位置取出相关信息，合成一份新的表示。

它的输出仍然是一个向量。之后还要经过后续层和词表预测，才能变成下一个 token。

2. 基本运算：加权求和

三个位置的 Value
v1=[10,0], v2=[0,10], v3=[6,6]
给三个位置分配权重
a1=0.6, a2=0.3, a3=0.1
按权重相加
o =a1v1+a2v2+a3v3； =0.6[10,0]+0.3[0,10]+0.1[6,6]； =[6.6,3.6]
写成求和式
o=∑j=13ajvj

其中 ∑ 就是“逐项相加”的缩写。只要权重非负、总和为 1，这也可以叫加权平均。

Attention 的核心问题因此变成：这些权重怎样根据当前需要自动产生？

3. 从输入表示得到 Q、K、V

注意力权重的计算需要为每个位置构造三种表示：

符号 名称 运算中的作用
q Query，查询 表示当前位置用什么条件寻找信息
k Key，键 提供用于匹配的特征
v Value，值 提供实际被加权汇总的内容

它们都从输入表示 x 计算出来：

q=xWQ, k=xWK, v=xWV

WQ,WK,WV 是训练得到的参数矩阵。“判断某条信息是否相关”和“取走这条信息的哪些内容”可以是两种不同的处理。让 K、V 使用不同变换，给模型更多自由度。

3.1 矩阵乘法的计算过程

输入与投影矩阵
x=[2,3], W=120011
逐列计算输出
xW=[2×1+3×0,  2×2+3×1,  2×0+3×1]=[2,7,3]

每个输出数字，都是输入数字的一种加权组合。因此，xWQ 可以读成：用 WQ 规定的组合方式，把输入特征重新组合成 Query 特征。

“投影”“线性层”“线性变换”在这里描述的就是这类运算。神经网络里称作“投影”的操作也可以增加维度，不一定是降维。

3.2 矩阵乘法的维度关系

代入本例的维度
x⏟1×2W⏟2×3=xW⏟1×3
推广到任意维度
(a×b)(b×c)⟶(a×c)

中间两个尺寸必须相等。 阅读矩阵公式时，可以先标出各矩阵的尺寸，以确认乘法顺序和每一步的输出形状。

4. 用 Q 与 K 的点积计算分数

当前 Query
q=[1,0]
三个历史 Key
k1=[2,0], k2=[1,1], k3=[0,2]
与第一个 Key 做点积
q⋅k1=1×2+0×0=2
与其余两个 Key 做点积
q⋅k2=1, q⋅k3=0

于是得到分数 s=[2,1,0]。在这个例子里，Query 只关心第一维，因此第一维更大的 Key 得分更高。

对于真正的模型，Q、K 的坐标由训练得到。训练会调整投影矩阵，使这种打分有助于预测后续 token。

点积为何会写成 qk⊤

这里统一采用行向量记法。上标 ⊤ 表示转置，也就是把行变成列：

k1⊤=20
用矩阵乘法计算点积
qk1⊤=[1,0]20=2
核对输出维度
(1×d)(d×1)⟶1×1

输出是一个数，正好用于打分。

6. 点积注意力的统一公式

省略缩放的加权和
ot=(∑j≤teqtkj⊤vj) / (∑j≤teqtkj⊤)

逐段翻译：

  • qtkj⊤：当前位置 t 和历史位置 j 的匹配分。
  • eqtkj⊤：把匹配分变成正权重。
  • 分子：按这些权重汇总 Value。
  • 分母：把权重总和归一化。
  • j≤t：只使用当前位置及之前的信息。

苏剑林在线性注意力文章中采用的一个很有帮助的切入点，就是把矩阵形式展开成这种归一化加权求和。这样才能看出哪些部分可以更换、哪些部分可以提前计算。文章原文

6.1 缩放因子的位置

按 Key 的维度缩放
stj=(qtkj⊤) / (√(dk))

其中 dk 是 Q、K 的维度。维度越多，点积中累加的项越多，分数的典型幅度可能变大。分数差异过大时，softmax 容易接近“一个权重为 1，其余都为 0”，影响训练。

在分量独立、均值为 0、方差为 1 的简化假设下，点积的方差是 dk，除以 √(dk) 可以把它稳定下来。Transformer 原论文，第 3.2 节

前面的手算例子省略了这个缩放。若加入它，权重的具体数值会变化，整个计算流程不变。

7. 从一个 Query 到整句话：矩阵形式

按行排列 Query
Q=q1q2⋮ qn
写出三个矩阵的维度
Q,K∈Rn×dk, V∈Rn×dv

符号 Rn×d 表示“有 n 行、d 列的实数矩阵”。于是 QK⊤ 就是所有 Query 对所有 Key 的分数表：

Key 1 Key 2 Key 3
Query 1 q1k1⊤ q1k2⊤ q1k3⊤
Query 2 q2k1⊤ q2k2⊤ q2k3⊤
Query 3 q3k1⊤ q3k2⊤ q3k3⊤

对每一行分别做 softmax，就得到注意力权重矩阵 A。最后：

O=AV

这个矩阵乘法的第 t 行，恰好就是：

ot=∑jatjvj
合并缩放、遮罩与归一化
O=softmax  ⁣((QK⊤) / (√(dk))+M)V

M 是因果遮罩：允许的位置加 0，未来的位置加 −∞，让未来位置的 softmax 权重变成 0。

矩阵公式将对各个 Query 的相同计算合写为一次批量运算。

8. 多头：同时用多套匹配方式读取历史

一个头只有一套 Q、K、V 变换。多头注意力 MHA 使用多套：

qt(h)=xtWQ(h), kj(h)=xjWK(h), vj(h)=xjWV(h)

上标 (h) 是“第几个头”的编号，不是乘方。每个头独立计算：

ot(h)=Attention (qt(h),K(h),V(h))

最后把结果拼起来，再做一次输出变换：

yt=[ot(1),ot(2),…,ot(H)]WO

例如 [1,2] 和 [3,4] 拼接后变成 [1,2,3,4]。这样模型可以同时使用多种读取方式。各个头的具体分工由训练形成，没有预先规定某个头必须负责语法或指代。

9. 为什么要缓存 K、V

假设模型已经读过“小明出生在北京”，正在生成后面的文字。

因果模型中，加入新 token 不会改变过去位置已经计算好的表示。因此，过去的 K、V 可以保存下来，后续直接使用。这就是 KV cache。

通常不缓存过去的 Q，是因为下一步要计算的是新位置如何读取历史。它需要新的 Query 和历史 K、V；过去的 Query 所对应的读取已经完成了。

两个推理阶段因此有所不同：

  • Prefill　处理输入的一长串 token，建立缓存。
  • Decode　逐个处理新 token，不断读取并追加缓存。

对标准 MHA，若有 L 层、历史长度 n、H 个头，缓存中的数字数量约为：

nLH(dk+dv)

如果 dk=dv=dh，就是 2nLHdh。历史越长，缓存越大。生成时反复读取缓存，还会消耗显存带宽。

11. MLA 的起点：学习共享表示

拼接两组 Key 和 Value
cj=[kj(1),kj(2),vj(1),vj(2)]

那么一个头取得自己的 Key，本质上是在 cj 里选出某一段。“选出某一段”也是一种矩阵乘法，例如：

[2,3,5,7]10010000=[2,3]

这个矩阵只会选坐标。如果允许矩阵里的数自由学习，就可以更灵活地组合共享信息：

kj,h=cjUK,h, vj,h=cjUV,h

于是不同头可以从同一份 cj 中，形成不同的 K、V。这正是苏剑林引入 MLA 时强调的视角：从固定的分割、复制，推广到可以学习的线性组合。文章 MLA 部分

问题随之出现：不同头又有了不同的 K、V，如果全部展开后缓存，缓存岂不是又变大了？MLA 的下一步就是解决它。

12. 利用矩阵结合律调整计算顺序

固定一个注意力头
kj=cjUK, vj=cjUV

12.1 Key 一侧的变换

原来的打分是 qtkj⊤。代入 kj=cjUK：

qtkj⊤ =qt(cjUK)⊤； =qtUK⊤cj⊤； =(qtUK⊤)cj⊤
转置法则与结合律
(AB)⊤=B⊤A⊤, (AB)C=A(BC)
先变换当前 Query
q̃t=qtUK⊤

再直接拿它与缓存的 cj 打分：

qtkj⊤=q̃tcj⊤

原本施加在每条历史记录上的变换，被移到了当前 Query 上。

数值验证

两种算法共用的输入
c=[2,3], UK=1201, q=[1,2]

先展开 Key：k=cUK=[2,7]。于是：

qk⊤=1×2+2×7=16

调整乘法顺序：q̃=qUK⊤=[5,2]。再与 c 打分：

q̃c⊤=5×2+2×3=16

结果相同。

12.2 Value 一侧的变换

注意力输出为 ot=∑jatjvj。代入 vj=cjUV：

ot =∑jatj(cjUV)； =(∑jatjcj)UV

因为所有历史位置使用同一个 UV，可以先在潜在向量上求和，最后再变换一次。于是核心计算变为：

q̃t =qtUK⊤；atj =softmax j(q̃tcj⊤/τ)；ut =∑jatjcj；ot =utUV

这里 τ 表示原来的缩放系数。吸收以后不能按照变换后的向量宽度随意修改它，否则会改变原来的函数。

这解释了为什么能只缓存 cj，却仍完成对应的多头计算。注意两个细节：

  1. 两种计算顺序给出相同的 softmax 输入。 调整发生在打分公式内部的线性运算。
  2. 这是给定 MLA 参数之后的代数等价改写。 并不意味着任何已有的 MHA 都可以无损压成任意小的 MLA。浮点计算中，不同计算顺序还会有舍入差异。

原始 MLA 的 KV 联合压缩与矩阵吸收，可对应到 DeepSeek-V2 报告第 2.1 节。

MLA 的共享向量来自：

cj=xjD

假设 xj∈R1×d，cj∈R1×r，其中 r 比完整的多头 KV 总宽度小很多。于是一个头的 Key 是：

kj,h=xjDUK,h

对应的有效变换矩阵为 WK,h=DUK,h。秩可以先理解成：这个线性变换最多能独立传递多少个方向的信息。 因为中间只有 r 个数字：

rank (DUK,h)≤r

一个直观的例子

如果一个三维向量总是长这样：x=[a,b,a+b]，第三个数字可以从前两个算出来，那么只保存 c=[a,b] 就够了。通过：

[a,b]101011=[a,b,a+b]

可以恢复。但任意三维向量 [a,b,c] 没有这种保证。

MLA 也是如此：它把信息流限制在较小的中间表示里，训练要学会在这个限制下保留有用信息。所以应当区分：

  • 引入低维表示　改变模型的参数化和表达约束。
  • 对已经确定的低维模型做矩阵吸收　改变计算顺序，数学函数保持一致。

这一区分，比单独记住“MLA 是低秩压缩”更重要。

为什么 RoPE 会卡住矩阵吸收

位置相关的相对旋转会插入原本可提前合并的矩阵乘法。解耦后，内容留在低维潜空间，位置支路单独计算。

耦合边界

位置旋转夹在中间

(qt Rt)1 × d·(cj UK Rj)⊤d × 1=qt (Rt−j UK⊤) cj⊤1 × 1

RₜRⱼᵀ = Rₜ₋ⱼ。该旋转随历史位置 j 变化，无法把相乘结果提炼成固定的 q̃ₜ。

解耦 RoPE

让内容与位置各走一条打分支路

潜向量 cⱼ
单份共享位置键 kⱼᴿ
(qtC UK⊤)1 × d_c·cj⊤d_c × 1+qtR1 × d_rope·kjR⊤d_rope × 1

Prefill/训练可按头展开，用规则矩阵算子。Decode 可缓存低维 C 和每位置单份位置键，再在 Query 侧吸收内容投影。

14. RoPE 对矩阵吸收的影响

位置编码要让注意力感知顺序和距离。RoPE 的基本想法是：把向量中的数字两两组成二维向量，再按照 token 位置旋转。不同维度对使用不同旋转频率。

把位置 t 对应的旋转矩阵记作 Rt。旋转之后：

qtrot=qtRt, kjrot=kjRj
计算旋转后的点积
qtRtRj⊤kj⊤
合并为相对旋转
RtRj⊤=Rt−j

可以直观理解为：两根箭头各自旋转后，它们的相对角度取决于旋转角度之差。这样，注意力分数就能感知位置差 t−j。

现在代入 MLA 的 kj=cjUK：

qtRt−jUK⊤cj⊤

这里的限制是，中间的旋转随历史位置 j 改变。 因此没法像之前那样，只算一个与 j 无关的 q̃t=qtUK⊤，就对所有 cj 完成同样的打分。

额外留一小部分维度承载 RoPE

拆分内容与位置分量
qt=[qtC,qtR], kj=[kjC,kjR]
  • C：不施加 RoPE 的部分。
  • R：施加 RoPE 的部分。
分别打分再相加
qtkj⊤=qtC(kjC)⊤+qtR(kjR)⊤

因此，大部分内容运算继续使用矩阵吸收；较小的 RoPE 分支提供位置相关性；历史缓存保存 cj，再加一个所有头共享的位置键 kjR。这种设计称为解耦 RoPE。DeepSeek-V2 报告第 2.1.3 节

“内容部分”和“位置部分”是计算路径的划分；它不保证每个向量在语义上只包含单一类别的信息。

15. MLA 为什么能在不同阶段采用不同形式

到这里，MLA 有两种看起来不同、但数学上对应的算法：

形式 主要做法
展开形式 从共享表示生成各头的 K、V，再计算多头注意力
吸收形式 各头调整自己的 Query，直接读取共享潜在表示

训练或长输入 prefill 时，可以采用更适合大规模矩阵计算的形式；逐 token decode 时，可以采用更有利于缓存和带宽的形式。

苏剑林在《MLA 好在哪里？（下）》中着重分析的，就是训练计算成本与解码缓存成本的不同需求。这是一种解释 MLA 设计取舍的分析框架，实际速度还取决于硬件、批量大小和具体实现。文章原文

MLA 的完整逻辑链：共享一份历史表示 → 允许不同头学习不同读法 → 通过结合律避免缓存展开结果 → 用小的 RoPE 分支保留位置能力。

瓶颈 ·MLA 缩小单个位置的缓存宽度。对超长上下文，历史位置数 n 仍可能很大。

16. MLA 压缩单条记录，历史位置数保持不变

假设历史有 100 万个 token。即使每个 token 的缓存很小，完整注意力依然要对大量历史位置打分。因此可以进一步提出：先花较少成本找出相关位置，再用主注意力读取它们。这是稀疏注意力的一条重要思路。

DSA 的两阶段计算

先由轻量索引器打分：

Itj=Indexer (xt,xj)

取索引分数最大的 k 个位置：

St=TopK j(Itj)

然后主注意力在这些位置上重新计算：

ot=(∑j∈Stestjvj) / (∑j∈Stestj)

索引分数 Itj 与主注意力分数 stj 分别用于候选筛选和最终注意力计算。 上面是简化的流程表达式。

DeepSeek-V3.2 的 DSA 使用 lightning indexer，并在 MLA 上实现这种选择机制。索引器训练会对齐主注意力的分布，使它学会选择有用位置。DeepSeek-V3.2 技术报告

收益来自昂贵的主注意力只处理少量位置；风险在于索引器可能漏选。当前 Query 的 Top-k 也不能代表未来 Query 的 Top-k，所以没有被这一次选中的历史缓存，不能据此永久删除。

此外，索引器搜索本身也需要计算。主注意力变稀疏，不自动意味着整个模型的计算复杂度严格线性。

17. V4 加入“沿序列压缩”

需要区分两种压缩。假设历史表示的尺寸为 n×d：

  • 压缩特征宽度　主要缩小 d，保留逐 token 的记录。
  • 压缩序列长度　主要缩小 n，把若干 token 汇成一条记录。

用一个教学模型表示第二种：

cˉb=∑j∈Bbβbjcj

其中 Bb 是第 b 个 token 块，βbj 是压缩权重，cˉb 是这个块形成的新记录。这和前面的加权求和很像，区别是它在构建供以后查询的历史表示。

这是简化示意式。实际压缩器可以对不同通道使用不同权重，还可能包含位置处理、归一化和块重叠。

V4 报告中有两种全局注意力：

结构 核心步骤
CSA 先压缩历史序列，再用索引器选少量压缩条目
HCA 使用更强的序列压缩，注意力读取可见的压缩条目，不再做同样的 Top-k 稀疏选择

它们都结合局部滑动窗口，以保留近处的细节；核心采用共享 KV 的 MQA 形式。V4 的 CSA 压缩器还有重叠结构，不能简单等同于不重叠平均池化。DeepSeek-V4 报告第 2.3 节

压缩减少了历史记录的数量，也可能使单条记录中的细节更难恢复。

18. V4.1 的 CSA2：减少跨层重复

前面讨论的主要是单层。如果许多层都单独保存全局 KV、单独索引，又会产生大量重复成本。

V4.1 的 CSA2 为不同层指定三种模式：

模式 全局 KV 索引选择
Full 本层生成 本层重新选择
Reindex 复用前层 本层重新选择
Reuse 复用前层 复用已有选择

每层仍有自己的主 Query 和局部 SWA KV。 因此，即便使用同一份历史记录和同一组候选位置，不同层仍可以计算不同权重与输出。

从数学上看，假设两个层共享历史矩阵 C，它们仍然可以有：

A(ℓ)=softmax  ⁣(Q(ℓ)C⊤/τ)
A(ℓ+1)=softmax  ⁣(Q(ℓ+1)C⊤/τ)

因为 Query 不同，两个权重矩阵通常不同。共享 KV 不等于共享整个注意力输出。

CSA2 还在 Decoder 中采用分层索引：第一次全范围索引建立较大的候选池，后续 Reindex 在池中挑选。它节省后续层的搜索量，但第一次全范围扫描仍保留。V4.1 报告第 2.3 节

模型整体还采用 CED：Decoder 的全局 KV 来源于因果 Encoder 的最终表示。这让大部分输入 token 无需完成完整 Decoder 计算就能建立相应全局缓存；局部 SWA 还有额外处理。V4.1 模型说明

  1. 减少每条记录的存储
  2. 减少主注意力读取的位置
  3. 把部分历史汇成更少记录
  4. 减少不同层重复保存与重复索引

这是设计动机的串联，不表示新模型完整保留了每一代的所有结构。

线性注意力：更换核函数、外积状态与 RNN 递推

19. 平方复杂度的来源

为方便计算，先设 Q、K、V 都是 n×d。标准注意力首先需要 QK⊤，尺寸为：

(n×d)(d×n)=n×n

这包含 n2 对匹配，每对需要约 d 次乘加，所以计算量约为 O(n2d)。符号 O(⋅) 描述增长趋势：固定 d，序列长度翻倍，这部分工作大约变成四倍。

先考虑去掉 softmax 的情形

变成 O=(QK⊤)V。根据结合律：

(QK⊤)V=Q(K⊤V)
先汇总 Key 和 Value
K⊤V⏟d×d
再用 Query 读取
Q⏟n×d(K⊤V)⏟d×d

两次乘法总共约为 O(nd2)。固定 d，它随 n 线性增长。

运算顺序改变以后，中间对象从“token 对 token 的大表”变成了“特征对特征的小表”。

但标准公式是 softmax (QK⊤)V。softmax 夹在中间，不能直接套用刚才的结合律。这里讨论的是计算量；是否显式保存整个分数矩阵，还取决于具体实现。

20. 回到加权平均：更换相关性函数

标准注意力可以写成：

ot=(∑j≤teqtkj⊤vj) / (∑j≤teqtkj⊤)

先把指数点积记成一个一般的相关性函数 κ(q,k)，于是：

ot=(∑j≤tκ(qt,kj)vj) / (∑j≤tκ(qt,kj))

这就是苏剑林文章里很有用的推广方向：把注意力理解为由相关性函数决定的归一化加权平均。《Attention 必须有个 Softmax 吗？》

现在选择一种能够分开处理 Q、K 的函数：

κ(q,k)=ϕ(q)ϕ(k)⊤

ϕ 叫特征映射，意思是把原来的向量变成另一种特征表示。

为了使权重非负，一个充分条件是让 ϕ 的各分量非负。例如经典线性 Transformer 使用逐元素的 ELU (x)+1。“充分条件”表示这样做能保证非负，并不表示只有这一种做法。《Transformers are RNNs》

21. 将 Query 移到求和之外

代入可分解的相关性函数
ot=(∑j≤t[ϕ(qt)ϕ(kj)⊤]vj) / (∑j≤tϕ(qt)ϕ(kj)⊤)

对于固定的 t，ϕ(qt) 不随 j 改变。所以分子可以变成：

∑j≤t[ϕ(qt)ϕ(kj)⊤]vj=ϕ(qt)[∑j≤tϕ(kj)⊤vj]
对分母提出 Query
ϕ(qt)[∑j≤tϕ(kj)⊤]
记下两项历史状态
St=∑j≤tϕ(kj)⊤vj, zt=∑j≤tϕ(kj)⊤
用两个状态求输出
ot=(ϕ(qt)St) / (ϕ(qt)zt)

这是归一化线性注意力的核心形式。实际实现还会处理分母过小等数值问题。

St 的含义

假设 ϕ(k) 有 r 维，Value 有 dv 维：

ϕ(kj)⊤⏟r×1vj⏟1×dv

结果为 r×dv。这种“列向量乘行向量”的操作叫外积。

运算 尺寸 结果
点积 qk⊤ 行乘列 一个数
外积 k⊤v 列乘行 一张矩阵

点积用来打一个匹配分；外积把 Key 的每个分量与 Value 的每个分量建立联系。

22. 用同一组数字验证线性注意力

沿用相同的 Query、Key 和 Value
q=[1,0], K=201102, V=10001066

这组数字都非负，因此本例可以直接使用 ϕ(x)=x，也就是令相关性为普通点积。这只适用于当前例子的非负条件；任意真实 Q、K 不能直接这样保证非负。

方法 A：逐条计算相关性

三个权重的未归一化值为 [2,1,0]。归一化以后：

[(2) / (3),(1) / (3),0]
按位置加权得到输出
o=(2) / (3)[10,0]+(1) / (3)[0,10]=[(20) / (3),(10) / (3)]≈[6.6667,3.3333]

方法 B：先构造历史状态

先计算 S=K⊤V：

S =20[10,0]+11[0,10]+02[6,6]； =20000+010010+001212； =20101222
累加归一化状态
z=20+11+02=33

于是 qS=[20,10]，qz=3，得到：

o=([20,10]) / (3)=[6.6667,3.3333]

两种方法结果相同，说明结合律改写是成立的。 但前面 softmax 注意力的结果是 [7.1926,2.9875]。两者不同，因为相关性函数已经从 eqk⊤ 换成了 qk⊤。

这个数字例子把两件事明确分开：

  • 更换相关性函数，会改变模型的计算结果。
  • 在选定的线性注意力内部，改变结合顺序，结果保持一致。

23. 线性注意力的状态递推

观察 St=∑j≤tϕ(kj)⊤vj。到了下一个位置，只多了一项：

St=St−1+ϕ(kt)⊤vt
累加归一化状态
zt=zt−1+ϕ(kt)⊤

初始化为 S0=0、z0=0。因此每一步只需要：

  1. 读取旧状态 St−1,zt−1。
  2. 加入当前 token。
  3. 用当前 Query 读取更新后的状态。

历史越来越长，状态的形状仍然是：

St:r×dv, zt:r×1

这就是它与循环神经网络 RNN 的联系：把历史累计在一个可更新的状态中。 原始线性 Transformer 论文直接推导了这种递推形式。论文第 3.3 节

“线性”的主要含义是：固定特征维度后，处理序列的计算量随长度线性增长。它不要求 ϕ 必须是线性函数，也不表示整个模型是线性的。

24. Softmax 注意力的精确状态表示为何难以压缩

展开标量指数函数
eqk=1+qk+(q2k2) / (2)+(q3k3) / (6)+⋯
将各阶项写成特征
ϕ(q)=[1, q, (q2) / (√(2)), (q3) / (√(6)),…]

那么 ϕ(q)ϕ(k)⊤=eqk。问题是：要对一般输入精确成立，这个展开通常需要无限多项。

截断为有限维，就变成近似；换成另一种有限维特征映射，则可能是在定义另一种相关性函数。

因此，有限维线性注意力的效率收益通常伴随着表示方式的变化。它把历史汇入固定大小的状态，逐条区分历史信息的方式也随之改变。

相比之下，保留逐 token KV 的注意力，可以在每个新 Query 到来时重新对历史记录分配权重。二者各有适用的效率与能力取舍。

还要注意：上面的固定状态大小说的是这类递推推理状态，训练并不因此自动拥有与序列长度无关的总显存。这部分推导讨论的是基础归一化线性注意力；带遗忘门或其他状态更新规则的变体需要进一步展开。

最值得真正算懂的，是下面三个式子。

Attention 怎样读取信息：

ot=∑jatjvj

MLA 怎样把历史一侧的变换移到 Query 一侧：

qt(cjUK)⊤=(qtUK⊤)cj⊤

线性注意力怎样先汇总历史，再回答 Query：

∑j(qtkj⊤)vj=qt(∑jkj⊤vj)

前两个仍然可以保留逐 token 的历史；第三个在相应的打分形式下，把历史合成了一份状态。
