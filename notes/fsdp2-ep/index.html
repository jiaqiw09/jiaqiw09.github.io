01

路由约定与数学等价前提

一个 token 在这里是一行长度为 H 的隐藏向量。对序列长度 S 的单样本，Attention 输出为 [S,H]，router 给每行分配 top-k 个专家；下面只观察一个 EP 组。

01 向量展开

Token 与 Top-k

[S,H] → [S·topk,H]

每条路由记录对应一个原 token 的一个 top-k 槽位。

02 权重边界

专家分片

输入 DP 分片和专家权重的归属不同。目标专家在对端时，需要把对应的 token 行发过去。

03 布局不变量

两次 Permute

先按目标 Rank 形成发送段，再按本 Rank 专家聚类，使 Grouped MatMul 的输入连续。

04 数学等价

路由权重加权和

相同输入、专家函数、路由和权重下，最终加权和保持一致。

数学本质 ·z[i,k] = Expert[top_k_index[i,k]](token[i])，output[i] = ∑k top_k_weights[i,k] · z[i,k]。浮点实现可能因计算顺序或 kernel 选择出现舍入差异。

拓扑口径 ·4 卡、ep_size=2 时，EP group 可为 {卡0,卡1} 与 {卡2,卡3}。图中只展示前一组，同一 EP 组的两个 Rank 持有不同输入 token。

05

反向传播与工程边界

位置重排的反向沿原排列的逆映射返回。专家梯度和路由权重梯度需要各自按所有权归位。

01 反向所有权

派发与返还的反向

↔ All-to-All 逆映射

梯度经过两次交换的转置，输入与输出 splits 互换。专家分片的参数梯度留在拥有该专家的 Rank，跨副本归约按对应的 FSDP/DP 组执行。

02 有效记录边界

权重与有效槽位

同一个 token 的多个专家梯度在原 Rank 按路由槽位回填。若实现启用 capacity、token drop 或 padding，反向应复用一致的掩码与索引。此玩具例子每条路由均有效。

TAKEAWAY

Permute 维护排列和分段，All-to-All 搬运 token 行，Grouped MatMul 批量执行本地专家。路由、索引和权重始终按同一原始槽位对齐，最终仍是同一个 MoE 加权和。
