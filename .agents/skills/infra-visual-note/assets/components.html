两次投影为何可以调整计算顺序

输入 X 有 m 行样本、每行 k 个特征。矩阵 A 把特征宽度从 k 投到 h，矩阵 B 再投到 n，输出记作 Y。

连续两步都是线性投影时，结合律允许先合并权重。调整前后，各次乘法的缩并维度和需要保留的中间张量会发生变化。

01 起点

连续线性投影

X[m,k] · A[k,h] · B[h,n]

中间表示有 h 个特征。

02 瓶颈

先投影每行输入

(X · A)[m,h]

先生成宽度为 h 的中间张量，其体积随样本行数和宽度增长。

03 性质

矩阵乘法结合律

(X · A) · B = X · (A · B)

实数域下输出相同，两次乘法的分组可以调整。

04 优化

复用合并权重

W[k,n] = A[k,h] · B[h,n]

固定权重的推理可以缓存 W，把合并移出重复执行路径。

用同一组数字验算两条路径

取 X = [2, 3]，A 的两行为 [1, 2]、[0, 1]，B 的一列为 [2, 1]。先展开输入，或先把两张权重相乘，都会得到一个 1 × 1 的输出。

两边分步写出缩并维度和每个元素的乘加，便于逐项核对输入、中间值和输出。

工程边界 ·结合律适用于这个纯线性关系。加入非线性或更换浮点求值次序后，需要分别核对数学条件与数值误差。

按缩并轴切分后，跨卡归约哪一部分

把 X 的特征轴和 W 的行轴分别按 k 切给两个 Rank。局部下标 r 表示 Rank 编号，zr 表示它在本地算出的部分和。

每张卡独立计算一个贡献，对两个贡献做 SUM 后，每张卡都得到完整的 Y。

RANK 0 特征 0 阶段与通信契约 RANK 1 特征 1

输入分片

  1. X₀=2
  2. W₀=4
z0 = X0 @ W0  # (1 × 1), (1 × 1) -> (1 × 1)

本地缩并得到部分和 8。
STAGE 1

本地矩阵乘法

两个输入分片按同一个特征下标配对，本地就能计算。

输入分片

  1. X₁=3
  2. W₁=1
z1 = X1 @ W1  # (1 × 1), (1 × 1) -> (1 × 1)

本地缩并得到部分和 3。

部分和与归约结果

  1. z₀=8
  2. Y=11
Y0 = sum_tp(z0)  # (1 × 1) -> (1 × 1)

完整输出在 Rank 0 可用。
STAGE 2

↔ All-Reduce (SUM)

TP 组 {0, 1} 各输入和输出 1 个逻辑元素，逐元素求和，张量形状不变。没有 scatter 或 gather 轴。

部分和与归约结果

  1. z₁=3
  2. Y=11
Y1 = sum_tp(z1)  # (1 × 1) -> (1 × 1)

完整输出在 Rank 1 可用。

反向传播如何回到输入分片

  1. 01 设置上游梯度

    dY₀[1,1]=[1], dY₁[1,1]=[0]

    只在 Rank 0 取这一次逻辑 loss 的梯度，避免对复制输出重复计数。

  2. 02 转置归约

    All-Reduce(SUM): ([1], [0]) → ([1], [1])

    SUM 复制映射的转置仍是组内逐元素 SUM。每个 Rank 的局部输出梯度为 [1]。

  3. 03 求本地输入梯度

    dXᵣ[1,1] = dzᵣ[1,1] · Wᵣᵀ[1,1]

    Rank 0 得到 [4]，Rank 1 得到 [1]。每卡持有自身特征的梯度，DP=1 无数据并行归约。

工程边界 ·此例切的是特征轴，输入为满长单行，不涉及 padding 掩码或跨序列分片的 Shift 标签。1 个逻辑元素是每 Rank 的接口负载，实际链路字节取决于集合算法和传输协议。

TAKEAWAY

矩阵结合律允许把固定权重的合并移出重复计算。把缩并轴切给两个 Rank 后，本地结果仍是部分和，需要在 TP 组归约成完整输出。核对形状、作用域和字节口径，就能同时检查等价推导与实现代价。
