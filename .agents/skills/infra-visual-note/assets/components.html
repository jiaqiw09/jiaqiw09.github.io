按缩并轴切分后做 SUM

切分缩并轴后，每卡只拿到一个部分和。跨两个 Rank 求和才能还原完整输出。

Rank 0 · k=0算子与通信契约Rank 1 · k=1

z0 = x0 * u0  # shape [1,1] → [1,1]

local_matmul

两个 Rank 持有缩并轴的不同位置，各自计算局部乘积。

x₁=3u₁=1
z1 = x1 * u1  # shape [1,1] → [1,1]

得部分和 3。

STAGE 2跨卡归约

↔ All-Reduce (SUM)
