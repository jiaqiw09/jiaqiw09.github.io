# 工程图解讲义风交付自检

## 文章与外壳

- [ ] 只包含文章画布。外层阅读器的站点导航、目录和背景没有在正文里重复实现。
- [ ] 文章用同一份相对路径 CSS，正文 HTML 无内联样式、`<style>`、运行时脚本、外部字体和 Base64 字体包。关闭网络后仍可打开本地 HTML 和 CSS。
- [ ] 内容超过 3 个主体章节时，标题下方有一行编号胶囊，顺序与章节一致。每个锚点唯一、有效。Spec Bar 统一向量方向、符号、手算数字、拓扑与工程口径。
- [ ] 大节开头有 2–4 句自然导语，接着是图解。每个模块能在同一处找到动作、原因、签名或形状和一个可核验例子。
- [ ] 各级标题和正文使用同一无衬线体系。图区文字紧凑，模块间有间隔。代码、槽位、序号、数值使用等宽字体与等宽数字。无 Emoji、无手写 `<br>`。

## 图解与配色

- [ ] 左右表达对照或并行持有，上下表达时间或层级，中列承担阶段和通信契约。箭头的起点、终点、方向、数量、线型和交叉均正确。
- [ ] 蓝是输入或常规持有，绿是数学成立、优化或结果，琥珀是边界或瓶颈，珊瑚红是反例，紫是集合通信或跨设备互联。每个着色单元有可见文字或位置标签。
- [ ] 对等设备或 Rank 都用浅蓝，标签和列位置明确，包括紫色通信阶段。没有另设主题色、暗色反转、粗重外框或阴影。
- [ ] 多栏对照、工作台、泳道、横向流水线和宽表使用带可访问标签的 `ivn-scroll`，内层选一个标准最小宽度。窄桌面窗口里仅模块有横向滚动，页根不横向溢出。Tab 可聚焦滚动区域，左右方向键可查看隐藏列。
- [ ] 在完整桌面宽度和实际阅读窗格分别打开，检查标题、图示箭头、边界和列对齐。打印预览下解除滚动，A4 横向能展开内容，长表能按行分页并重复表头。

## 推导、通信和账本

- [ ] 符号首次出现时就解释意义和下标。逐项核对输入、输出和内侧消去维度。矩阵括号、符号下括注及相同结果标签与正文一致。
- [ ] 按 Spec Bar 的同一组整数，从头手算朴素、优化与分片路径。软最大值、指数、舍入、低精度误差或溢出结论与运算定义一致。注明等价成立的前提。
- [ ] 每段流水线包含步骤名、接口/张量签名、动作与理由。每行泳道伪代码都有形状注释。逐阶段核对进出 Rank、数据是否重排或归约、scatter/gather 轴和每 Rank 元素量。
- [ ] 前向和反向作用域明确。检查 padding/mask、跨片标签、反向通信和梯度归约范围，或注明为何不适用。区分逻辑数据量和算法/链路实际收发量，避免重复归约或重复计 loss。
- [ ] 账本中的 MAC 和字节有算式，注明精度、工程规模、单位、计数口径以及预计算、常驻、临时或峰值的差异。高亮方案有可见标签和适用条件。估算、理论值与实测结果分别标明。
