# 交付前七项验收

- [ ] **零页面补丁。** 公共 CSS 与各笔记里没有页面专属类和选择器。每个 HTML 的 body 类精确为 `ivn`。与样板使用同一公共 CSS。
- [ ] **零内嵌样式与裸公式。** 排查内页的内联样式、`<style>`、`<math>`、运行时脚本和 Base64 资源。拓扑只用语义化内联 SVG 与公共色值。
- [ ] **零硬换行和装饰图符。** 检查 `<br>` 和 Emoji。多行伪代码用 `pre.ivn-code`，关键调用各占一行并写 shape 注释。
- [ ] **章节契约。** 逐一比对 Jump Bar 的链接、编号和 <code>section[id]</code>，确认全存在且顺序相同。每节编号、导语、首个图解和全文终局卡完整。
- [ ] **组件契约。** 两个分布式页面有三栏泳道、槽位、量化账本和终局卡。跨设备阶段用自动紫色中轴，对等 Rank 同色。RDMA 有 SVG、五步流水线和带宽账本。数学页至少三个工作台、六个维度公式、CSS 矩阵和数量账本。
- [ ] **几何实测。** 在主页分别以 1440px、768px、390px 逐篇切换。核对页根无横向溢出，宽图可在各自容器横向滚动，无重复侧栏，长代码不粘连，样板与文章同构。
- [ ] **内容与打印复核。** 对比原锚点、引用与算式，验算相等结果、MB/KiB 及各 Rank 发送量。验证打印时解除滚动，阶段不被截断。记录使用的估算条件与浏览器结果。
